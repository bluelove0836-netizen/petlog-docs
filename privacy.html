펫로그 개인정보 처리방침

시행일: 2026년 5월 13일
'펫로그'(이하 "서비스")는 이용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목 및 수집 방법

항목수집 방법목적
앱인토스 익명 식별키 (Anonymous Key)자동 수집이용자 데이터 식별·관리
반려동물 정보 (이름, 종류, 품종, 생일, 체중, 사진 등)이용자 직접 입력반려동물 프로필 및 기록 관리
건강 기록 (예방접종, 동물병원 방문, 활동 기록 등)이용자 직접 입력건강 이력 관리 및 알림
사진 (반려동물 프로필 사진, 활동 사진)카메라 촬영 또는 앨범 선택반려동물 기록 저장
위치 정보 (위·경도)이용자 동의 후 기기에서 수집주변 동물병원·펫샵 검색

2. 개인정보의 보유 및 이용 기간

  • 익명 식별키: 서비스 이용 기간 동안 보관하며, 이용자가 연결 끊기 시 즉시 삭제됩니다.
  • 반려동물 정보·건강 기록·사진: 이용자의 기기(앱인토스 Storage) 에 저장되며, 앱 데이터 초기화 또는 연결 끊기 시 삭제됩니다.
  • 위치 정보: 주변 검색 요청 시 일회성으로 사용되며, 서버에 저장하지 않습니다.

3. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다.

4. 외부 API 데이터 송신

서비스는 다음 공공·외부 API에 최소한의 데이터를 송신합니다. 개인 식별 정보는 전송하지 않습니다.

  • 농림축산식품부 공공데이터 포털 (반려동물 정보, 위치 좌표)
  • 카카오맵 API (주변 장소 검색, 위치 좌표)
  • Open-Meteo (날씨 정보, 위치 좌표)
  • 한국관광공사 (펫 동반 여행지 정보)

5. 권한 요청 안내

권한사용 목적미허용 시
카메라반려동물 사진 촬영사진 촬영 불가 (앨범 선택은 가능)
사진 앨범반려동물 프로필·활동 사진 선택앨범에서 사진 불러오기 불가
위치주변 동물병원·펫샵 검색주변 검색 기능 이용 불가
알림예방접종·정기 케어 리마인더푸시 알림 수신 불가

6. 이용자의 권리

  • 이용자는 언제든지 토스 앱 내 [연결 끊기]를 통해 익명 식별키 및 관련 데이터 삭제를 요청할 수 있습니다.
  • 기기에 저장된 데이터는 미니앱 데이터 초기화 또는 앱 삭제로 즉시 제거할 수 있습니다.
